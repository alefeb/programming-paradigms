# Лабораторная работа №1
## Сравнение парадигм программирования на Python

Язык: Python 3.11+

### Сквозная задача
Для списка `[4, 7, 2, 9, 12, 5, 8, 3]` выбрать чётные числа, возвести их в квадрат и найти сумму.

Ожидаемый результат: `228`.

### Индивидуальный вариант №7
Найти среднее значение чётных чисел.

Для набора `[4, 7, 2, 9, 12, 5, 8, 3]` чётные числа: `4, 2, 12, 8`.
Среднее значение: `(4 + 2 + 12 + 8) / 4 = 6.5`.

### Структура
- `01_imperative.py` — императивный стиль
- `02_procedural.py` — процедурный стиль
- `03_oop.py` — объектно-ориентированный стиль
- `04_functional.py` — функциональный стиль
- `05_event.py` — событийный стиль, tkinter
- `individual_imperative.py` — вариант №7, императивный стиль
- `individual_procedural.py` — вариант №7, процедурный стиль
- `individual_functional.py` — вариант №7, функциональный стиль

### Запуск
```bash
python 01_imperative.py
python 02_procedural.py
python 03_oop.py
python 04_functional.py
python 05_event.py
python individual_imperative.py
python individual_procedural.py
python individual_functional.py
```

Для `05_event.py` откроется окно с кнопками вычисления и очистки результата.
